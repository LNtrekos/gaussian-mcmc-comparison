# Gaussian MCMC comparison

Simulation Assignment 6 compares RWM, MALA and Gaussian Invariant MALA for a
100-dimensional Gaussian target. The report explains the algorithms,
results and corrected control variates.

- `utils.R`: the three sampling functions and a trace-plot function.
- `run_example.R`: target setup, sampling, trace plots, ESS and control variates.
